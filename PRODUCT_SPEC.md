# PRODUCT_SPEC.md — KaamWala: Hyperlocal Worker-Services Marketplace

## Overview

**KaamWala** is a hyperlocal worker-services marketplace connecting customers in Mysuru, Karnataka, India with skilled local workers (plumbers, electricians, carpenters, cleaners, etc.).

**Launch market**: Mysuru, Karnataka, India  
**Primary language**: English (Kannada, Hindi planned)  
**Currency**: INR (stored as integer paise)  
**Timezone**: Asia/Kolkata (IST, UTC+5:30)
